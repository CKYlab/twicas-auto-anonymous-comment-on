# ツイキャス 匿名コメント自動ON

ツイキャスの配信ページで、コメント欄の三点メニューから「匿名コメントをONにする」を自動でクリックするユーザースクリプトです。

## 特徴

- 配信ページを開いたときに匿名コメントを自動でONにします
- 「Xにも投稿」のチェックボックスは操作しません
- `twitcasting.tv` と `ja.twitcasting.tv` の両方に対応しています
- 日本語 / 英語 / 韓国語 / 中国語（繁体）のUIで動作確認済みです
- すでに匿名コメントがONの場合は、追加操作せずに終了します

## 注意

- 起動時に一瞬コメントメニューが開く場合がありますが、匿名コメントをONにするための正常な動作です
- ツイキャス側の仕様変更により、動作しなくなる可能性があります
- 配信者側の設定やログイン状態によっては、匿名コメントをONにできない場合があります
- 使用は自己責任でお願いします

## インストール

1. Tampermonkey / Violentmonkey などのユーザースクリプト管理拡張機能をインストールします
2. `twicas-auto-anonymous-comment-on.user.js` をインストールします
3. ツイキャスの配信ページを開くと、自動で匿名コメントがONになります
